# Sequence Models

This folder contains two sequence-modeling projects in PyTorch.

## [FC_LSTM_BiLSTM](FC_LSTM_BiLSTM/)
Fully connected, LSTM, and bidirectional LSTM classifiers that predict blood-brain barrier penetration from one-hot encoded SMILES strings (BBBP).

## [Poetry_Generation](Poetry_Generation/)
Fine-tuning of the Persian GPT-2 model `HooshvareLab/gpt2-fa` to generate the second hemistich of Ferdowsi couplets.
